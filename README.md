# INGENIA AI

Aplicación web Streamlit de apoyo para Ingeniería Civil.

## Publicar
En Streamlit Community Cloud selecciona este repositorio, rama `main` (o la rama principal que aparezca) y archivo `app.py`.

## Ejecutar localmente
`pip install -r requirements.txt`
`streamlit run app.py`

Esta versión inicial incluye control básico de avance/costos, borradores de informes y preparación de requerimientos CAD/BIM. No sustituye software de ingeniería certificado ni revisión profesional.
